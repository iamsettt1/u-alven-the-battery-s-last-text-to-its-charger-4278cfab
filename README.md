The phone battery's last text message to the charger it waited for all day — one line of plain text, at most 200 characters. The battery held on at 1% all the way home, only to find the charger had been in the bag the whole time. The punchline lands in the last words: no alarm tomorrow.

## Run it

```sh
node main.ts
```

It prints exactly one line and writes the same line to `/output/entry.txt`.
